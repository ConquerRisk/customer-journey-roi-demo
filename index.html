The caution that makes this teachable. Customers were not assigned to these journeys; they chose them. Someone who sets up a payroll account was already more engaged. So the observed gain is an upper bound on what an intervention can produce, which is why the capture rate above is a separate, explicit assumption rather than hidden in the model. The honest sequence is: rank with the model, then run a randomised holdout on a few thousand customers, then replace the capture assumption with the measured effect. The break-even figure tells you what that test has to beat.

Using this in class

Three moves, in order. One: the model produces a ranking, not value — the tree alone changes nothing. Two: value appears only when the ranking is embedded in a process that reaches customers, which is what the reach and cost inputs represent. Three: the number everyone quotes (the observed gain) is the one that does not survive contact with causality, so the exercise is to find the capture rate at which the investment breaks even and ask whether a test could plausibly beat it.

Data: Santander product-recommendation records, 2015-01 to 2016-05, 775,348 customers. Journey states are combinations of held products; the outcome is products held at the end of the observed window. Teaching demonstration, not a business case.
